# 雷区推演 · Minesweeper Probability Coach

一个现代风格的网页扫雷，带「概率教练」：提示功能只根据屏幕上看得到的数字和总雷数做推理，不读取雷的真实位置，用来练习判断。

## 运行

下载 `扫雷.html`，双击用浏览器打开即可，无需安装。

## 提示是怎么算的

1. **规则推理**：单个数字规则 + 两个数字比较（1-2 类定式），写出完整推理链。
2. **全局枚举**：对边界做精确计数（边界状态动态规划），结合剩余雷数加权，找出在所有可能布局里都安全的格子。
3. **必须猜时**：给出每个格子的精确雷率和风险最低的位置，并说明原因。

## 功能

- 初级 / 中级 / 高级 / 自定义，首击及周围保证无雷
- 概率图（M）、提示（H）、新局（N）、插旗模式（F）
- 实时教练：每一步评价为「确定安全 / 最优猜测 / 可以更稳 / 不必要的冒险」
- 棋盘带行列坐标轴；提示里的坐标可悬停 / 点击，在棋盘上定位
- 提示按钮是开关，再按一次恢复到提示前的页面
- 踩雷后可返回上一步（Z）：只显示踩中的雷，返回后盘面恢复到这一步之前的样子；用过返回的局不计入最佳用时
- 踩雷复盘、定式速查、最佳用时与胜率
- 浅色 / 深色主题，支持触屏长按插旗
